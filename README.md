# Practice Repository

A personal practice repository for implementing and learning data structures and algorithms in JavaScript.

## Contents

### Stack Implementations
Collection of stack-based algorithm solutions:
- **Baseball_Game.js** - Baseball game score calculation
- **Asteroid_Collision.js** - Asteroid collision simulation
- **Backspace_String_Compare.js** - String comparison with backspace handling
- **Daily_Temperatures.js** - Next warmer temperature finder
- **find132pattern.js** - Find 132 pattern in array
- **Largest_Rectangle_in_Histogram.js** - Maximum rectangle area in histogram
- **Minimum_Add_to_Make_Parenthese_Valid.js** - Minimum parentheses to add
- **nearest_to_left.js** - Nearest greater element to left
- **nearest_to_right.js** - Nearest greater element to right
- **nearest_smallest_to_left.js** - Nearest smaller element to left
- **Next_Greater_Element_I.js** - Next greater element (version 1)
- **Next_Greater_Element_I_left.js** - Next greater element from left
- **Next_Greater_Element_II.js** - Next greater element (circular array)
- **nextGreaterElements2.js** - Next greater elements (version 2)
- **Remove_Adjacent_Duplicates.js** - Remove adjacent duplicate characters
- **Remove_K_Digits.js** - Remove K digits to get smallest number
- **stock_span_1.js** - Stock span problem
- **Trapping_Rain_Water.js** - Rain water trapping problem
- **valid_parenthisis.js** - Valid parentheses checker

### Linked List Implementations
- **Linked-List/index.js** - Complete linked list implementation with methods
- **linked-List-Prac.index.js** - Linked list practice exercises including cycle detection

### Web Files
- **index.html** - Basic HTML page
- **style.css** - Styling for HTML page
- **index.js** - JavaScript functionality
- **test.js** - Test implementations

## Running the Code

Each JavaScript file can be run independently using Node.js:

```bash
node Stack/Baseball_Game.js
node Linked-List/index.js
```

## Dependencies

This project uses:
- Express.js (for potential server implementations)

Install dependencies:
```bash
npm install
```

This repository serves as a personal learning space for:
